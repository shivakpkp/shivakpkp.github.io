ABOUT ME

Cloud engineering,
grounded in operations.

I'm Shiva Koochakpour, a Toronto-based Senior Cloud and Platform Engineer with more than eight years of experience across systems administration, site reliability and cloud engineering. I build repeatable Azure infrastructure and automation, with an operator’s focus on reliability, access control and troubleshooting.

From systems to platforms.

My background spans infrastructure operations, banking and regulated healthcare. That progression has shaped how I approach cloud engineering: understand the application’s dependencies, make changes repeatable, and verify how the system behaves after deployment.

At LifeLabs, my work includes Terraform infrastructure, reusable environment patterns, CI/CD with Azure DevOps and GitHub Actions, PowerShell automation, and troubleshooting across cloud networking, identity and applications.

DELIVERY & IMPACT

Make infrastructure easier to deliver and operate.

Through reusable Terraform and self-service environment patterns, I helped reduce provisioning time from two days to under ten minutes. These patterns made development and test infrastructure more consistent and reduced the manual work needed to prepare environments.

My cost-optimization work includes scheduling and tearing down non-production resources, alongside dashboards that support App Service and Azure SQL sizing decisions. I use infrastructure as code to make the resulting configuration changes repeatable.

ENGINEERING IN PRACTICE

Connect infrastructure decisions to application needs.

For an App Service and Azure SQL application, I worked with Terraform modules, remote state and managed identity access. When the application could not connect to SQL, the resolution required creating the managed identity’s database user—an example of troubleshooting across infrastructure, identity and the application’s dependencies.

My AKS experience includes a private platform for .NET frontend and backend services, container images in ACR, NGINX ingress, horizontal pod autoscaling and connectivity to an on-premises database through ExpressRoute.

Build automation with clear decisions and outcomes.

My App Service Plan scaling project brings Terraform provisioning, GitHub Actions delivery, Azure Monitor alerts and PowerShell runbooks together. The runbooks evaluate scaling conditions and safeguards, then verify the result of a capacity change. Read-only Python checks provide a separate way to verify the deployed configuration.

The project reflects how I approach engineering: automate a concrete operational need, make the decision logic explicit, and distinguish a successful change from a request that should be skipped.

How I work.

I start by understanding requirements and operational constraints, then translate them into reusable infrastructure and delivery workflows. When something fails, I investigate across networking, identity, infrastructure and application behavior rather than stopping at the first error message.

I value clear documentation and knowledge sharing so that the solution can be understood and maintained by the team. My goal is to improve both the way infrastructure is delivered and the experience of operating it afterward.
