# Shiva — Cloud & Platform Portfolio

A responsive, photo-free static portfolio for GitHub Pages. No build tools, external fonts, JavaScript libraries or installation are required.

## Preview

Open `index.html` in a browser. All pages use relative links and work locally or on GitHub Pages.

## Publish on GitHub Pages

1. Create a public repository named `shivakpkp.github.io` in your GitHub account.
2. Upload the **contents** of this folder into the repository root (not the enclosing folder). Keep the `projects` directory intact.
3. Commit the files to `main`.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**, then `main` and `/ (root)`, and save.
6. Wait for the Pages deployment to finish. GitHub will display the published address.

If you already have a Pages repository, integrate these files on a new branch and review before replacing an existing site.

## Edit the portfolio

- `index.html`: introduction and featured projects.
- `projects.html`: project index and expandable additional repositories.
- `about.html`: professional background and technical focus.
- `projects/*.html`: individual case studies.
- `style.css`: shared colors, typography and responsive layout.

The two experience case studies are based on your described work. Review their wording before public publication. They intentionally omit internal identifiers and do not link workplace code. Public repositories are linked separately. No email address, LinkedIn URL or resume link has been invented; add those when ready.

The design takes inspiration from the reference portfolio's dark palette and case-study structure, with original layout details and text. No portrait or third-party assets are required.
