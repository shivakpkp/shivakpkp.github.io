App Service Plan scaling automation

Metric-driven scaling with Terraform, Azure Monitor and PowerShell runbooks.

TerraformPowerShellAzure MonitorPythonDocker
01

The challenge

Reduce the manual effort involved in adjusting App Service Plan capacity.

02

My contribution

I used modular Terraform to provision Automation resources, metric alerts and action groups, with PowerShell runbooks handling scaling. GitHub Actions separates planning from deployment.

03

Engineering decisions

The scaling design includes tag-based selection, cooldowns and checks for supported SKU transitions. Docker-based Python verification checks deployed Azure resources without issuing scaling calls.

04

What this demonstrates

A deployed and tested automation project connecting monitoring, infrastructure delivery and resource verification.
