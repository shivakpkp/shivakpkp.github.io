Application infrastructure with Terraform

Repeatable App Service and Azure SQL environments with identity-based application access.

App ServiceAzure SQLManaged IdentityTerraform
01

The challenge

Provision consistent application environments and make configuration changes repeatable.

02

My contribution

I used Terraform modules and remote state for environment-specific App Service and SQL infrastructure, with pipeline checks and managed identity for application access.

03

Engineering decisions

One connection issue required creating the managed identity user inside SQL: assigning an identity to the application alone did not grant database access. Monitoring informed sizing changes, which were managed through Terraform.

04

What this demonstrates

An end-to-end example of infrastructure delivery, identity troubleshooting and environment lifecycle management.
