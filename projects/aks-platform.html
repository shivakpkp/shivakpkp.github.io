Private AKS application platform

A private Kubernetes platform for .NET services with hybrid connectivity and controlled access.

AKSACRExpressRouteRBACHPA
01

The challenge

Run frontend and backend services on AKS while connecting to an on-premises database.

02

My contribution

I worked on private AKS infrastructure, VNet peering and connectivity through ExpressRoute. The application used ACR for container images, NGINX ingress and horizontal pod autoscaling.

03

Engineering decisions

This design brings networking, identity and application delivery together. Azure AD authentication and Kubernetes RBAC control access; CI/CD deploys Kubernetes manifests. Troubleshooting spans image pulls, ingress, application health and database connectivity.

04

What this demonstrates

Practical experience operating a private application platform across cloud and on-premises boundaries.
